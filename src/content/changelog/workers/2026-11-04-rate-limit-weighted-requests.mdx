The [Rate Limiting binding](/workers/runtime-apis/bindings/rate-limit/) now accepts an optional `delta` in `limit()`. A call counts as `delta` requests instead of one, so you can weight requests by what they cost without calling `limit()` in a loop.

For example, assign one unit to a product lookup and 10 units to an expensive search. Both operations consume the same user's allowance. The following handler takes a verified user ID from your application's authentication flow:

<TypeScriptExample filename="src/index.ts">

```ts
export async function handleAuthenticatedRequest(
	request: Request,
	env: Env,
	userId: string,
): Promise<Response> {
	const { pathname } = new URL(request.url);

	// Assign searches a weight of 10 and other requests a weight of 1.
	const delta = pathname === "/search" ? 10 : 1;

	const { success } = await env.MY_RATE_LIMITER.limit({
		key: userId,
		delta,
	});
	if (!success) {
		return new Response("Rate limit exceeded", { status: 429 });
	}

	return new Response("Success!");
}
```

</TypeScriptExample>

The `delta` defaults to `1`. To use `delta` in local development, use [Wrangler 4.157.0](https://github.com/cloudflare/workers-sdk/releases/tag/wrangler%404.157.0) or later.

For more details, refer to [Weighted requests](/workers/runtime-apis/bindings/rate-limit/#weighted-requests).
